## Software Engineer

I worked as a **Software Engineer**, where I gained hands-on experience in **Java programming, Android application development, software engineering, Agile/Scrum development, and web technologies**. This industry experience allowed me to apply programming and software engineering concepts to real-world software projects.

### Java & Android Development

I developed Android application features using **Java and Android Studio**. My work involved implementing application logic, developing user-interface components, debugging code, testing functionality, and maintaining existing application features.

I applied **object-oriented programming (OOP)** concepts, including classes, objects, encapsulation, inheritance, and polymorphism, while developing Java-based application components.

### Software Engineering & Agile/Scrum

Our development team followed an **Agile software development process using the Scrum framework**. I participated in the iterative development of software features and collaborated closely with other developers throughout the development process.

My experience included:

- Participating in **Sprint Planning** and **Daily Scrum** meetings.
- Developing and testing assigned features during each sprint.
- Translating software requirements into implementation tasks.
- Debugging and resolving software issues.
- Collaborating with team members to integrate application components.
- Maintaining and improving existing software based on project requirements.

This experience provided practical exposure to different stages of the **Software Development Life Cycle (SDLC)**, including requirements, design, implementation, testing, debugging, and maintenance.

### Web & Back-End Development

I also contributed to a **government project management system** and other web-based development activities. My work included:

- Developing back-end components using **PHP and CakePHP**.
- Working with **MySQL** for database-driven applications.
- Developing web components using **HTML, CSS, and JavaScript**.
- Integrating front-end, back-end, and database components.
- Testing, debugging, and maintaining web application functionality.
